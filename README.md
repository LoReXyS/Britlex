# Britlex

A modern and responsive landing page for learning English.

## 📖 About the project

Britlex is a responsive website created for an English learning platform.

The project focuses on practicing frontend development skills, creating a clean user interface and making the website responsive for different screen sizes.

## 🚀 Technologies

- HTML5
- CSS3
- JavaScript
- Vite

## ✨ Features

- Responsive design
- Modern and clean interface
- Navigation menu
- Information sections about English courses
- Pricing section
- Contact section
- Adaptive layout for desktop, tablet and mobile devices

## 📱 Responsive Design

The website is adapted for different screen sizes:

- 💻 Desktop
- 📱 Tablet
- 📱 Mobile
